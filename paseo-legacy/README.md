# paseo-legacy

Chain specs for the **pre-substitute-relay Paseo** (original genesis, `Paseo Testnet`,
protocol-id `pas`, ss58 `0`). Archived here when the network was relaunched from block 0 as the
substitute relay (new genesis; top-level `paseo.raw.json` — `Paseo`, protocol-id `pad`, ss58 `42`).

These are kept for historical reference / access to the retired chain's DBs. They are **not** the
live network — do not use them to sync the current Paseo.
